Quick answers

Before you ask

Will my tool be shut down?

The transition window is about coverage, not shutdowns. Only high-risk uses go to review — with their owner part of the path.

Could this run inside SPARK instead?

Often yes — same capability, Ministry GPUs, data never leaves. If the follow-up suggests it, or you simply prefer it, apply for a workspace.

I don't know my data classification

Choose "not sure" — a perfectly acceptable answer; the data team takes it from there with you.
