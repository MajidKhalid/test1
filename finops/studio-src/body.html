FinOps Report Studio Studio v1

Internal operator tool for the FinOps owner. Never publish or share this file. The report it generates (FinOps_Dashboard.html) is the shareable one. Nothing dropped here leaves your browser.
See the report preview
  1. Pull the exports. GCP_Data_Pull_Runbook.md for the Google Cloud Reports CSVs and Azure_Data_Pull_Runbook.md for the Azure Cost analysis CSVs. Pull on the 3rd of the month or later.
  2. Drop each file into its slot. The readiness list tells you what is still missing, what does not reconcile and what the report will say if you publish as is.
  3. Write the FinOps statement of the month, refresh the credit positions and the notes. Tokens such as {{gcp.net}} fill themselves from the files.
  4. Generate. Check the preview below, then upload FinOps_Dashboard.html to SharePoint over the previous edition so the link never changes. Keep the versioned copy as the archive and save the edition state next to the CSVs.

1Edition

The published report only carries the Quarter tab in quarter-end editions (March, June, September, December). The preview below shows every period that has data so you can check it.

2Data request · Google Cloud

Billing > Reports, grouped by Service or by Project, with the credits and discounts options switched on. The file name gives the date range; the header row is checked on drop.

Credit position (Riyals) · from Billing > Credits and the purchase-order ledger
Key highlight override · empty = automatic (fastest-growing service at 3% of net or more)
Project to general-department map

One line per project: project-id = cyber | itsvc | business | other. The account-level bucket is the blank id and is split by service (Chronicle and Security Command Center stay Cybersecurity; Fortinet Security SaaS moves to IT Services GD). A project missing from this table stops the build with its name.

3Data request · Microsoft Azure

Cost Management > Cost analysis, Actual cost, grouped by Service name, Subscription name or Resource location, downloaded as CSV at the billing-account scope.

Credit position (Riyals) · from Cost Management + Billing > Credits (MCA) or Enrollment > Prepayment (EA)
Key highlight override · empty = automatic
Subscription to general-department map

One line per subscription: subscription name or id = cyber | itsvc | business | other. Matching is case-insensitive on either the name or the id. An unmapped subscription is listed in the readiness list and blocks the build until it is mapped.

4FinOps statement of the month

The statement opens the report, above the cloud switch. Write it to say where we are, what we are dealing with and where we are heading. Tokens: {{month}} {{prevMonth}} {{gcp.net}} {{gcp.gross}} {{gcp.discounts}} {{gcp.change}} {{gcp.sandbox}} {{gcp.top.name}} {{gcp.top.share}} {{gcp.td.net}} {{gcp.credit.remaining}} {{gcp.credit.pct}} {{azure.net}} {{azure.change}} {{azure.top.name}} {{azure.top.share}} {{azure.credit.remaining}}

5Readiness and generate

    Generate is enabled once every required item above is green. The downloads land in your Downloads folder. The stable name is the one SharePoint overwrites; the versioned name is the archive copy. Your edits are kept in this browser automatically; the JSON state is the copy to keep with the month's CSVs.
