How to pull these files (about ten minutes per cloud)

Google Cloud · Billing > Reports

  1. Open Billing > Reports for the Ministry's billing account (needs the Billing Account Viewer role).
  2. Set the date range to the month, the 1st to the last day. Set Group by: Service. In the panel on the right keep every credits and discounts option on. Download CSV: this is the by-service file.
  3. Change to Group by: Project and download again: the by-project file.
  4. Back to Group by Service, add the filter Projects = prj-moenergy-iw-sb-development and download again: the sandbox file.
  5. Clear the filter and set the date range to 1 October 2025 to today for the contract-to-date by-service file. By project and sandbox for that range are optional.
  6. Keep the names Google writes: the date range in the name is how the Studio files them. Pull on the 3rd of the month or later; the data lags up to two days.

Microsoft Azure · Cost Management > Cost analysis

  1. Open Cost analysis with the scope set to the Ministry's billing account (needs Cost Management Reader). Leave Actual cost selected.
  2. Set the date range to the month. Group by: Service name, then Download > CSV: the by-service file.
  3. Group by: Subscription name, download again: the by-subscription file. Group by: Resource location for the optional region file.
  4. Set the date range from the contract start to today and download by Service name again: the contract-to-date file.
  5. Name each file with its range, for example azure_by_service_2026-08-01_2026-08-31.csv. A file without dates in its name is filed under the reporting month.
  6. Read the credit or prepayment balance from Billing > Credits (MCA) or Enrollment > Prepayment (EA) and type it in step 3.

The one trap: a Google export pulled with the credits and discounts options off shows Subtotal equal to List cost on every row, and the Studio refuses it. The full runbooks are GCP_Data_Pull_Runbook.md and Azure_Data_Pull_Runbook.md in the finops folder.

Credits: the balance is added up, not typed

Microsoft Azure credit

With a starting credit, the Azure balance is computed as starting minus the Azure contract-to-date spend; without one, the portal balance is shown as read.
